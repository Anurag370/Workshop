# File System
| Command | Description                                        |
| ------- | -------------------------------------------------- |
| **pwd** | Prints current working directory                   |
| **ls**  | Prints a list of contents in the current directory |
| **cd**  | Changes current directory                          |
| **cat** | Outputs the content of a file                      |
| **cp**  | Copies files from Current to Destination           |
| **rm**  | Removes each specific files                        |
