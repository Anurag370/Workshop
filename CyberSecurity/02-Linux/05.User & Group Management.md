# User & Group Management
| Commands     | Description     |
| ------------ | --------------- |
| **useadd**   | Add user        |
| **usermod**  | Modify User     |
| **userdel**  | Delete User     |
| **passwd**   | Change Password |
| **groupadd** | Create Group    |
| **groupdel** | Delete Group    |
| **groups**   | User Groups     |
| **sudo**     | Run as root     |
| **su**       | Switch User     |
