# 1. AI vs ML vs DL

Think of them as nested concepts:

**Artificial Intelligence → Machine Learning → Deep Learning**

|Concept|Meaning|Example|
|---|---|---|
|**AI**|Broad field of making machines perform intelligent tasks|Chess-playing system|
|**ML**|AI systems that learn patterns from data|Spam email classifier|
|**DL**|ML using multi-layer neural networks|Image recognition|

### Simple mental model

> **AI** = Make machines intelligent  
> **ML** = Let machines learn from data  
> **DL** = Let neural networks learn complex patterns from large amounts of data

You don't need to dive into neural-network mathematics yet.

---

# 2. What is Data Science?

**Data Science** is the process of extracting useful information and insights from data.

A simplified workflow:

```text
Raw Data
   ↓
Data Cleaning
   ↓
Exploration / Visualization
   ↓
Feature Engineering
   ↓
Machine Learning
   ↓
Evaluation
   ↓
Insights / Predictions
```

Important distinction:

**Data Science ≠ Machine Learning**

Machine learning is one of the tools used within data science.

# 3. Features and Labels 🎯

This is one of the **most important concepts** to understand.

Suppose we have:

|Hours Studied|Attendance|Previous Score|Passed|
|--:|--:|--:|---|
|2|60|45|No|
|5|80|65|Yes|
|8|90|82|Yes|
|1|50|35|No|

We want to predict whether a student passes.

### Features

The information used to make the prediction:

```text
Hours Studied
Attendance
Previous Score
```

These are **features (X)**.

### Label / Target

What we want to predict:

```text
Passed
```

This is the **target/label (y)**.

So:

```text
X = [Hours Studied, Attendance, Previous Score]

y = Passed
```

### Remember

> **Features → information given to the model**  
> **Target → answer the model is trying to predict**

# 4. Samples

A **sample** is one observation/record in your dataset.

For example:

```text
5 hours, 80% attendance, 65 previous score, Yes
```

That's **one sample**.

The table above contains **4 samples**.

So if your dataset has:

```text
1000 rows
```

you generally have:

```text
1000 samples
```

---

# 5. Training vs Testing

We don't want to train and evaluate a model on exactly the same data.

Instead:

```text
Dataset
   │
   ├── Training Data
   │       ↓
   │     Learn
   │
   └── Testing Data
           ↓
        Evaluate
```

For example:

```text
1000 samples
│
├── 800 → Training
└── 200 → Testing
```

The model learns patterns from the **training set**.

The test set represents **unseen data**.

### Why?

Imagine giving a student the exact questions they memorized and then testing them with the same questions.

They could score 100% without actually understanding the subject.

ML models can have the same problem.

# 6. Regression vs Classification

This distinction will become extremely important later.

## Classification

Predict a **category/class**.

Examples:

```text
Spam / Not Spam
Pass / Fail
Cat / Dog
Fraud / Not Fraud
```

Example:

```text
Input → Email
Output → Spam
```

### Classification means:

> Predict **which category** something belongs to.

---

## Regression

Predict a **continuous numerical value**.

Examples:

```text
House price → ₹65,00,000
Temperature → 31.5°C
Salary → ₹8,50,000
Sales → ₹2,40,000
```

Example:

```text
Input → House features
Output → ₹72,00,000
```

### Quick rule

> **Classification → category**  
> **Regression → number**

---

# 7. Supervised vs Unsupervised Learning

## Supervised Learning

You have:

```text
Features + Known Target
```

The model learns:

```text
X → y
```

Example:

```text
House size + location + bedrooms
              ↓
          House price
```

Because we know the correct answers during training, this is **supervised learning**.

Common supervised algorithms you'll study later:

- Linear Regression
    
- Logistic Regression
    
- Decision Trees
    
- Random Forest
    
- SVM
    
- KNN
    

---

## Unsupervised Learning

There is **no target/label**.

You give the algorithm data and ask it to discover patterns.

Example:

```text
Customer data
     ↓
ML algorithm
     ↓
Customer groups
```

For example, it might discover:

```text
Group 1 → Budget customers
Group 2 → Frequent customers
Group 3 → High-value customers
```

You didn't tell the algorithm these groups beforehand.

That's **unsupervised learning**.

# 9. Basic Probability & Statistics

You don't need advanced mathematics yet.

For this foundation stage, focus on:

## Probability

Understand:

- Probability between 0 and 1
    
- Events
    
- Conditional probability
    
- Independent events
    
- Basic probability distributions
    

Example:

```text
P(rain) = 0.7
```

means there's a 70% probability of rain.

---

## Statistics

Learn:

- Mean
    
- Median
    
- Mode
    
- Range
    
- Variance
    
- Standard deviation
    
- Percentiles
    
- Correlation
    

For example:

```text
Data = [10, 20, 30, 40, 50]

Mean = 30
```

You'll use these concepts heavily during **EDA and feature engineering**.
