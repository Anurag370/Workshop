# File Viewing and Editing
| Command  | Description            |
| -------- | ---------------------- |
| **cat**  | Display File           |
| **less** | Scroll through file    |
| **more** | View file page by page |
| **head** | First lines            |
| **tail** | Last Lines             |
| **nano** | Simple Editor          |
| **vim**  | Advanced editor        |
| **awk**  | Test processing        |
