# File System
| Command    | Description                                        |
| ---------- | -------------------------------------------------- |
| **pwd**    | Prints current working directory                   |
| **ls**     | Prints a list of contents in the current directory |
| **cd**     | Changes current directory                          |
| **cp**     | Copies files from Current to Destination           |
| **rm**     | Removes each specific files                        |
| **tree**   | Prints a directory tree                            |
| **mkdir**  | Creates a new directory                            |
| **rmdir**  | Remove empty directory                             |
| **touch**  | Creates an file                                    |
| **mv**     | Move or Rename files                               |
| **find**   | Finds Files                                        |
| **locate** | Search indexed files                               |
| **stat**   | Prints File metadata                               |
