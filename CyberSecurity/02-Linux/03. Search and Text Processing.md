# Search and Text Processing
| Commands  | Description        |
| --------- | ------------------ |
| **grep**  | Search Text        |
| **egrep** | Extended regex     |
| **cut**   | Extract Columns    |
| **sort**  | Sort text          |
| **uniq**  | Remove duplicates  |
| **wc**    | Count words/Lines  |
| **tr**    | Replace characters |
| **paste** | Merge Files        |
| **diff**  | Compares files     |
