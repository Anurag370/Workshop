# HSMC301 — Economics for Engineers (Humanities-II) — PYQ-Based Notes

Complete, beginner-friendly revision notes built **strictly from three MAKAUT previous-year question
papers**: 2022-2023, 2023-2024 and 2024-2025 (Paper Code HSMC301, UPID 003446, 70 marks / 3 hours).

> **How to use these notes.** Read [Chapter 01](01-Basics-and-Engineering-Economy.md) first if the
> subject is new to you. Then work through the chapters in order, because each one only assumes the
> previous ones (for example, contribution is explained *before* P/V ratio and break-even; discounting
> is explained *before* NPV and IRR). Finish with [Chapter 13](13-Numerical-Practice-Set.md),
> [Chapter 14](14-Formula-Sheet.md), [Chapter 15](15-Last-Minute-Revision.md) and the
> [70-mark mock test](16-Mock-Test-with-Solutions.md).

**Two kinds of content are always marked**

- `(PYQ 2022-2023, C-Q7)` — taken from, or directly answering, one of the three supplied papers.
- `(Supplementary)` — standard textbook explanation added so that the topic can be learned from zero;
  it was **not** seen in the supplied papers.

## How the exam should be attempted (70 marks, 3 hours)

| Block | Time to plan | Approach |
|---|---|---|
| Group A (10 marks) | 15 minutes | Write one crisp line per answer. For T/F, write "True/False — because …" in one line. Never leave a blank: an unanswered one-mark item is a guaranteed zero. |
| Group B (15 marks) | 35 minutes | Answer the **three** questions you know best. For theory: definition + 4 to 6 labelled points. For numerical: write every step — method marks are given even when the final number slips. |
| Group C (45 marks) | 95 minutes | Answer the **three** questions you know best. Mirror the printed internal marks split (e.g. 6+1+2+6) in your headings so the examiner can see the marks. |
| Review | 15 minutes | Check units (Rs, %, units), check that the arithmetic of totals is shown, and check that no question was left blank. |
