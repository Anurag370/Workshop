# 55. Correlation

Correlation measures the degree to which two variables are linearly related.

Pearson correlation coefficient:

r=Cov⁡(X,Y)σXσYr = \frac{ \operatorname{Cov}(X,Y) }{ \sigma_X\sigma_Y }

The value lies between:

−1≤r≤1-1 \leq r \leq 1

Interpretation:

|Correlation|Meaning|
|--:|---|
|+1|Perfect positive linear relationship|
|0|No linear relationship|
|-1|Perfect negative linear relationship|

Example:

```text
Study Hours ↑
      ↓
Marks ↑
```

This could indicate positive correlation.

> [!warning]  
> **Correlation does not necessarily imply causation.**

z=x−μσz = \frac{x-\mu}{\sigma}

### Min-Max Scaling

x′=x−xminxmax−xminx' = \frac{x-x_{min}} {x_{max}-x_{min}}

Typically maps values to the range $[0,1]$.

# 69. Avoiding Data Leakage

> [!warning]  
> **Data leakage occurs when information that should not be available during training leaks into the training process.**

Example:

```text
Test information
      ↓
Training process
      ↓
Artificially high performance
```

A common example is fitting preprocessing transformations using the entire dataset before splitting.

Instead:

```text
Training Data
     ↓
Fit preprocessing
     ↓
Transform training data

Test Data
     ↓
Use same fitted preprocessing
     ↓
Transform test data
```

# 73. Common Mistakes

### Mistake 1 — Using loops unnecessarily

Instead of:

```python
result = []

for x in arr:
    result.append(x * 2)
```

Prefer NumPy vectorization:

```python
result = arr * 2
```

---

### Mistake 2 — Ignoring missing values

Always inspect:

```python
df.isnull().sum()
```

---

### Mistake 3 — Not understanding the dataset

Don't immediately train a model.

First:

```text
Load
 ↓
Inspect
 ↓
Understand
 ↓
Clean
 ↓
Visualize
 ↓
Transform
 ↓
Model
```

---

### Mistake 4 — Treating correlation as causation

A strong correlation does not automatically mean that one variable causes the other.

---

### Mistake 5 — Data leakage

Never allow test information to influence model training or preprocessing.
