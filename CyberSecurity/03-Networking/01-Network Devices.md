# Network Devices

## Host
Hosts are any devices that sends or receives traffic.

**Examples**
- Computer
- Phone
- IOT devices
- Cloud Servers
- Servers

There are two categories of **Host**:
- Clients
- Servers

Clients initiate request, Servers responds.
Servers are simply computers with software installed which respond to specific requests.
[[Clients_VS_Servers]]
## IP Address
An IP Address is an identity of each host or an address of location
IP addresses are 32-bits
Bit = 1 or 0
```
1110001110000110000110011100011101
```

Represented as four octets
```
1000 1000 . 0001 0110 . 0001 0001 . 0110 0010
```

Each Octet can be 0 - 255
```
136.22.17.98
```

IP addresses are hierarchically designed
Suppose ACME Corp have rights to IP Addresses that start with 10.x.x.x
