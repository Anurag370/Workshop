# Machine Learning Paradigms

> [!abstract] Overview  
> **Machine Learning (ML)** is a field of Artificial Intelligence in which computers learn patterns from data and use those patterns to make predictions, classifications, decisions, or generate useful representations without being explicitly programmed for every task.

Machine Learning paradigms describe **how a machine learns from data and feedback**.

The major paradigms are:

1. **Supervised Learning**
    
2. **Unsupervised Learning**
    
3. **Semi-Supervised Learning**
    
4. **Self-Supervised Learning**
    
5. **Reinforcement Learning**
    

---

# 1. What is a Learning Paradigm?

A **learning paradigm** defines the relationship between:

- 📊 Data
    
- 🏷️ Labels
    
- 🧠 Model
    
- 🎯 Objective
    
- 🔄 Feedback
    

For example:

### Supervised Learning

```text
Input Data ──→ Model ──→ Prediction
    │                       │
    └────── Label ──────────┘
             ↓
        Calculate Error
             ↓
        Update Model
```

The model receives examples containing both **inputs and correct answers**.

### Reinforcement Learning

```text
       State
         ↓
       Agent
         ↓
      Action
         ↓
    Environment
         ↓
     Reward
         ↓
       Agent
```

The model learns through **interaction and rewards/penalties**.

|---|--:|---|---|

# 3. Supervised Learning

> [!important]  
> **Supervised learning learns from labeled data.**

The training dataset contains:

D={(xi,yi)}i=1nD = \{(x_i,y_i)\}_{i=1}^{n}

Where:

- $x_i$ = input/features
    
- $y_i$ = target/label
    
- $n$ = number of training examples
    

The model learns a function:

f(x)→yf(x) \rightarrow y

The objective is to learn a function that makes accurate predictions on **unseen data**.

---

## 3.1 Example

Suppose we want to predict whether an email is spam.

|Email|Label|
|---|---|
|"Win a free iPhone!"|Spam|
|"Meeting at 5 PM"|Not Spam|
|"Claim your prize now"|Spam|
|"Project report attached"|Not Spam|

The model learns the relationship:

```text
Email
  ↓
Feature Extraction
  ↓
ML Model
  ↓
Spam / Not Spam
```

# 4. Types of Supervised Learning

There are two major types:

1. **Classification**
    
2. **Regression**
    

---

## 4.1 Classification

Classification predicts a **discrete category**.

Examples:

- Spam / Not Spam
    
- Cat / Dog
    
- Disease / No Disease
    
- Fraud / Legitimate
    
- Pass / Fail
    

Mathematically:

f(x)→yf(x) \rightarrow y

where:

y∈{C1,C2,…,Ck}y \in \{C_1,C_2,\dots,C_k\}

---

### Binary Classification

Two classes.

Example:

```text
Input → Model → Spam / Not Spam
```

Examples:

- 0 / 1
    
- Yes / No
    
- Positive / Negative
    

---

### Multiclass Classification

More than two classes.

Example:

```text
Image
  ↓
Model
  ↓
Cat / Dog / Horse / Bird
```

---

### Multilabel Classification

One sample can belong to multiple classes.

Example:

A movie may be:

```text
Action + Comedy + Adventure
```

A regression model learns:

f(x)→yf(x) \rightarrow y

where $y$ is continuous.

# 7. Advantages of Supervised Learning

✅ Usually high predictive performance when sufficient labeled data exists.

✅ Clear training objective.

✅ Easy to evaluate using known labels.

✅ Useful for classification and regression.

---

# 8. Limitations of Supervised Learning

❌ Requires labeled data.

❌ Label creation can be expensive.

❌ Human labeling can introduce errors.

❌ Performance can suffer when training data does not represent real-world conditions.

# 9. Unsupervised Learning

> [!important]  
> **Unsupervised learning works with unlabeled data.**

The dataset contains:

D={x1,x2,…,xn}D = \{x_1,x_2,\dots,x_n\}

There is no predefined target $y$.

The model attempts to discover:

- Groups
    
- Relationships
    
- Structure
    
- Anomalies
    
- Lower-dimensional representations
    

---

## 9.1 Example

Suppose a company has customer information:

```text
Age
Income
Purchases
Visit Frequency
```

There are no predefined customer categories.

An algorithm may discover:

```text
Cluster 1 → High-value customers
Cluster 2 → Occasional customers
Cluster 3 → Low-engagement customers
```

The algorithm discovered the groups itself.

---

### 1. Clustering

### 2. Dimensionality Reduction

### 3. Association Rule Learning

Discovers relationships between variables/items.

### 4. Anomaly Detection

Identifies unusual observations.

# 11. Clustering

Clustering attempts to divide data into groups called **clusters**.

Example:

```text
       ● ●
      ● ● ●

                 ▲ ▲
                ▲ ▲ ▲

                         ■ ■
                        ■ ■ ■
```

Possible clusters:

```text
Cluster A → ●
Cluster B → ▲
Cluster C → ■
```

---

## 11.1 K-Means Clustering

K-Means is one of the most common clustering algorithms.

### Basic idea

Given $K$ clusters:

1. Select $K$ initial centroids.
    
2. Assign each point to the nearest centroid.
    
3. Recalculate centroids.
    
4. Repeat until convergence.
    

Objective:

min⁡∑k=1K∑xi∈Ck∥xi−μk∥2\min \sum_{k=1}^{K}\sum_{x_i \in C_k} \|x_i-\mu_k\|^2

Where:

- $C_k$ = cluster $k$
    
- $\mu_k$ = centroid of cluster $k$

```text

```

Popular techniques:

- PCA
    
- t-SNE
    
- UMAP
    
- Autoencoders

# 13. Association Rule Learning

Association learning discovers relationships between items.

A famous example is **market basket analysis**.

Example:

```text
Customers who buy:

Bread + Butter
       ↓
often buy
       ↓
Jam
```

Important concepts:

### Support

How frequently an itemset appears.

### Confidence

How often the rule is correct.

### Lift

How much stronger the relationship is compared with random occurrence.

Popular algorithm:

**Apriori**

# 15. Semi-Supervised Learning

> [!important]  
> **Semi-supervised learning uses a combination of labeled and unlabeled data.**

Example:

```text
10,000 images

100 labeled images
+
9,900 unlabeled images
```

Instead of ignoring the unlabeled data, the model attempts to exploit both.

---

## 15.1 Why Use Semi-Supervised Learning?

Labeling data can be expensive.

For example:

```text
10,000 medical images
        ↓
Doctors manually label them
        ↓
Expensive + Time consuming
```

Instead:

```text
100 labeled
+
9,900 unlabeled
        ↓
Semi-Supervised Learning
        ↓
Model
```

---

# 16. Common Semi-Supervised Techniques

### Pseudo-Labeling

The model predicts labels for unlabeled data.

```text
Unlabeled Image
       ↓
Existing Model
       ↓
"Cat" with 98% confidence
       ↓
Pseudo Label
```

The pseudo-labeled example can then be used for further training.

---

### Consistency Regularization

The model is encouraged to produce similar predictions when the same input is slightly modified.

```text
Original Image ──→ Model ──→ Cat
      │
      ↓
Augmented Image ─→ Model ──→ Cat
```

# 17. Self-Supervised Learning

> [!important]  
> **Self-supervised learning creates training targets from the data itself.**

It is technically a form of supervised learning because the model learns against a target, but the target is generated automatically rather than manually labeled.

---

## 17.1 Example: Text

Suppose we have:

```text
"The cat is sitting on the ___"
```

The model must predict:

```text
mat
```

The original text provides the training signal.

No human needs to manually label every example.

---

# 18. Types of Self-Supervised Learning

### Masked Prediction

Some information is hidden and the model predicts it.

```text
"The cat is [MASK] on the mat."

          ↓

"sitting"
```

Used by models such as BERT-style architectures.

---

### Autoregressive Prediction

Predict the next token.

```text
The cat is
     ↓
sitting
     ↓
on
     ↓
the
     ↓
mat
```

This is a fundamental training objective for many language models.

---

### Contrastive Learning

The model learns to bring similar representations closer and push dissimilar representations apart.

```text
Image A ──→ Representation A
   │
   └── Similar Image ──→ Representation B

A ↔ B = Close

Unrelated Image → Representation C

A ↔ C = Far
```

Examples include:

- SimCLR
    
- MoCo
    
- CLIP-style contrastive training
    

---

# 19. Why Self-Supervised Learning Matters

Modern AI systems can require enormous amounts of data.

Manually labeling billions of examples is impractical.

Self-supervised learning allows models to learn from large amounts of raw data.

```text
Huge Unlabeled Dataset
          ↓
Self-Supervised Objective
          ↓
Pretraining
          ↓
Learned Representations
          ↓
Fine-Tuning
          ↓
Specific Task
```

This is a major idea behind modern foundation models.

# 20. Reinforcement Learning

> [!important]  
> **Reinforcement Learning (RL) is learning through interaction with an environment using rewards and penalties.**

Instead of being given the correct answer, an **agent** learns which actions produce better long-term outcomes.

---

# 21. Components of Reinforcement Learning

The major components are:

### Agent

The learner or decision maker.

Example:

```text
Game-playing AI
```

### Environment

The world in which the agent operates.

Example:

```text
Game
```

### State

Current situation.

Example:

```text
Player position
Enemy positions
Health
```

### Action

What the agent can do.

Example:

```text
Move left
Move right
Jump
Attack
```

### Reward

Feedback received after an action.

Example:

```text
Enemy defeated → +10
Player damaged → -5
Game completed → +100
```

---

# 22. Reinforcement Learning Loop

```text
        ┌──────────────┐
        │    Agent     │
        └──────┬───────┘
               │
             Action
               ↓
        ┌──────────────┐
        │ Environment  │
        └──────┬───────┘
               │
        State + Reward
               │
               ↓
        ┌──────────────┐
        │    Agent     │
        └──────────────┘
```

The process repeats:

State→Action→Reward→New StateState \rightarrow Action \rightarrow Reward \rightarrow New\ State

---

# 23. Markov Decision Process

Reinforcement learning is commonly modeled using a **Markov Decision Process (MDP)**.

An MDP consists of:

(S,A,P,R,γ)(S,A,P,R,\gamma)

Where:

- $S$ = set of states
    
- $A$ = set of actions
    
- $P$ = transition probability
    
- $R$ = reward function
    
- $\gamma$ = discount factor
    

---

# 24. Policy

A **policy** determines what action the agent should take in a given state.

It is represented as:

π(a∣s)\pi(a|s)

Meaning:

> Probability of taking action $a$ given state $s$.

Example:

```text
State = Enemy nearby

Policy:

Attack → 70%
Run    → 20%
Hide   → 10%
```

---

# 25. Reward and Return

The agent does not only care about immediate reward.

It attempts to maximize **future cumulative reward**.

The return is:

Gt=Rt+1+γRt+2+γ2Rt+3+…G_t = R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\dots

Where $\gamma$ controls how much future rewards matter.

---

# 26. Exploration vs Exploitation

One of the central problems in RL is:

> Should the agent use what it already knows or try something new?

### Exploitation

Choose the action currently believed to be best.

### Exploration

Try other actions to discover potentially better strategies.

Example:

```text
Restaurant A
Known → 4.5★
Restaurant B
Unknown
```

Always choosing A = exploitation.

Trying B sometimes = exploration.

# 28. Q-Learning

Q-Learning learns a value function:

Q(s,a)Q(s,a)

which estimates how good it is to take action $a$ in state $s$.

The classic update rule is:

Q(s,a)←Q(s,a)+α[r+γmax⁡a′Q(s′,a′)−Q(s,a)]Q(s,a) \leftarrow Q(s,a)+ \alpha[ r+\gamma\max_{a'}Q(s',a')-Q(s,a) ]

Where:

- $\alpha$ = learning rate
    
- $r$ = reward
    
- $\gamma$ = discount factor
    
- $s'$ = next state
    

---

# 29. Deep Reinforcement Learning

When state spaces become very large, neural networks can approximate value functions or policies.

Example:

```text
Game Screen
     ↓
Neural Network
     ↓
Q-values / Policy
     ↓
Action
```

This is called **Deep Reinforcement Learning**.

A famous example is **DQN**, which combines Q-learning with deep neural networks.

# 32. How the Paradigms Relate to Modern AI

Modern AI systems often combine multiple paradigms rather than using only one.

For example, a modern language model may use:

```text
Raw Text
   ↓
Self-Supervised Pretraining
   ↓
Foundation Model
   ↓
Supervised Fine-Tuning
   ↓
Preference / Reward-Based Optimization
   ↓
AI Assistant
```

This is why the distinction between paradigms is important: **different stages of an AI system can use different learning signals.**

# 33. Choosing the Right Paradigm

Use **Supervised Learning** when:

- You have labeled data.
    
- You have a clearly defined target.
    
- You want prediction/classification.
    

Use **Unsupervised Learning** when:

- You don't have labels.
    
- You want to discover hidden structure.
    
- You want clustering or anomaly detection.
    

Use **Semi-Supervised Learning** when:

- You have a small amount of labeled data.
    
- You have a large amount of unlabeled data.
    

Use **Self-Supervised Learning** when:

- Large amounts of raw data are available.
    
- Manually labeling data is expensive.
    
- You want useful representations for downstream tasks.
    

Use **Reinforcement Learning** when:

- An agent must make sequential decisions.
    
- Actions affect future states.
    
- Feedback can be expressed through rewards.

# 38. Final Summary

Machine Learning paradigms describe **how models obtain their learning signal**.

The five major paradigms are:

1. **Supervised Learning** → learns from labeled examples.
    
2. **Unsupervised Learning** → discovers structure in unlabeled data.
    
3. **Semi-Supervised Learning** → combines labeled and unlabeled data.
    
4. **Self-Supervised Learning** → generates training targets automatically from raw data.
    
5. **Reinforcement Learning** → learns through actions, states, and rewards.
    

The central idea can be remembered as:

```text
Supervised       → Learn from answers
Unsupervised     → Discover structure
Semi-Supervised  → Learn from some answers + lots of data
Self-Supervised  → Create answers from the data
Reinforcement    → Learn from consequences
```
